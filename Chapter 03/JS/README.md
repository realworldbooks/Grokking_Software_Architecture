# Chapter 3: Coupling, Cohesion, and SOLID (JavaScript)

Welcome to the JavaScript/Node.js companion code for **Chapter 3**. 

## What's Inside

This directory contains standalone examples mapped directly to the book sections. Each folder contains a `Before` and `After` subfolder:

1. **Section 3.1: Coupling Test** (`/3.1 Coupling Test`)
2. **Section 3.2: Single Responsibility Principle** (`/3.2 SRP`)
3. **Section 3.3: Open/Closed Principle** (`/3.3 OCP`)

6. **Section 3.6: Dependency Inversion Principle** (`/3.6 DIP`)
7. **Section 3.7: OrderProcessor Refactor** (`/3.7 OrderProcessor Refactor`)

## How to Run the Code

This project is **100% zero-setup**. There is no `package.json`, and no `npm install` is required. Everything runs perfectly using vanilla Node.js.

To run an example, navigate to its specific Before or After folder in your terminal and execute the `index.js` file:

```bash
# Example: Running the refactored DIP lesson
cd "3.6 DIP/After"
node index.js

Alternatively, open the javascript folder in an IDE like VS Code, open the index.js file you want to test, and run it directly from your integrated terminal.
