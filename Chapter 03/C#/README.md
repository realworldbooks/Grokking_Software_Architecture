# Chapter 3: Coupling, Cohesion, and SOLID (C#)

Welcome to the C# companion code for **Chapter 3**. 

## What's Inside

This project is a single C# Console Application containing the following examples mapped directly to the book sections. Each section has a `Before` and `After` folder:

1. **Section 3.1: Coupling Test** (`/3.1 Coupling Test`)
2. **Section 3.2: Single Responsibility Principle** (`/3.2 SRP`)
3. **Section 3.3: Open/Closed Principle** (`/3.3 OCP`)
4. **Section 3.4: Liskov Substitution Principle** (`/3.4 LSP`)
5. **Section 3.5: Interface Segregation Principle** (`/3.5 ISP`)
6. **Section 3.6: Dependency Inversion Principle** (`/3.6 DIP`)
7. **Section 3.7: OrderProcessor Refactor** (`/3.7 OrderProcessor Refactor`)

## How to Run the Code

This project is **100% zero-setup**. There are no external NuGet packages required. 

To keep things simple, this project uses a single entry point. 

**Using an IDE (Visual Studio / VS Code):**
1. Open the `Chapter03/C#/` folder.
2. Open the `Program.cs` file in the root directory.
3. Uncomment the specific lesson you want to run (e.g., `SRP.After.Demo.Run();`).
4. Hit the **Play/Run** button!

**Using the CLI:**
Navigate to the directory in your terminal and run:
```bash
cd Chapter03/C#/
dotnet run
