# Chapter 3: Coupling, Cohesion, and SOLID (Java)

Welcome to the Java companion code for **Chapter 3**. 

## What's Inside

This is a standard Maven project containing the following examples mapped directly to the book sections. Each section package has a `before` and `after` sub-package:

1. **Section 3.1: Coupling Test** (`/3.1 Coupling Test`)
2. **Section 3.2: Single Responsibility Principle** (`/3.2 SRP`)
3. **Section 3.3: Open/Closed Principle** (`/3.3 OCP`)
4. **Section 3.4: Liskov Substitution Principle** (`/3.4 LSP`)
5. **Section 3.5: Interface Segregation Principle** (`/3.5 ISP`)
6. **Section 3.6: Dependency Inversion Principle** (`/3.6 DIP`)
7. **Section 3.7: OrderProcessor Refactor** (`/3.7 OrderProcessor Refactor`)

## How to Run the Code

This project is **100% zero-setup**. There are no external dependencies required. Everything runs perfectly using standard Java 17+.

**Using an IDE (IntelliJ, Eclipse, VS Code):**
1. Open the `chapter-03/java/` folder in your IDE.
2. Navigate to the specific section and state you want to run (e.g., `src/main/java/com/grokkingsoftwarearchitecture/chapter03/srp/after/`).
3. Open the `Main.java` file inside that package.
4. Right-click the file and select **Run 'Main.main()'**.
5. Watch the console output demonstrate the architectural lesson!
